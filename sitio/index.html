Cómo trabajamos

Hechas para durar y para confiar en ellas

Dos compromisos que valen para todas las aplicaciones, hoy y en cada versión.

01

Privacidad primero

Sin analítica, sin perfiles y sin rastreadores. Lo que escribes se queda en tu dispositivo, y si una aplicación sincroniza, viaja cifrado.

02

Código abierto

Todo el código está en GitHub con licencia MIT: puedes leerlo, compilarlo y comprobar lo que hace.
